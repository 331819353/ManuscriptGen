# 黄金前 3 秒钩子、口播人话改造与质检守则

写完初稿只是完成了 40%，真正决定视频有没有完播率的，是**前 3 秒能不能让人停下手指**、**念出来顺不顺嘴**，以及**是不是在“跟一个人面对面聊天”**。

## 一、双模式开场公式（Stop-Scroll vs 低姿态入座）

### 模式 A（`hook` 短/中视频强吸引科普）：黄金前 3 秒止滑钩子

前 3 秒一般只有 **10–22 个字**，必须瞬间完成“圈定受众 + 制造预期违背或切身危机”。

#### 5 大必杀钩子公式

| 公式类型 | 结构模型 | 示例（精准命中兴趣人群） |
| :--- | :--- | :--- |
| **1. 兴趣标签点名 + 反常识暴击** | 点名受众高频操作 + 直接判它“无效甚至反噬” | “熬夜开黑一宿，周末猛睡 12 个小时？别骗自己了，你越补觉周一越掉帧。” |
| **2. 切肤症状监控视角白描** | 精准复述一个只有受众才懂的私密窘态，让他怀疑你在偷窥 | “是不是一到晚上十一点，刚卸完妆就莫名想点全糖奶茶加炸鸡？” |
| **3. 替受众省钱防坑急刹** | 先叫停一个高消费或高成本动作，再给悬念 | “先别急着下单那瓶八百块的抗糖丸！它跟你在吃的真不是一回事。” |
| **4. 熟悉事物陌生化悬念** | 拿每天都见的东西问一个“其实你根本不知道为什么”的问题 | “每天喝的美式咖啡根本没给你充半点电，它只是偷偷把你的疲劳账单藏起来了。” |
| **5. 极端对比算账** | 用直观生活量级对比，制造强烈落差冲击 | “睡前刷 20 分钟手机，相当于把你熬夜抹的抗老精华直接刮掉一半。” |

### 模式 B（`companion` 深度陪伴独白）：低姿态信任入座开场（3 种反算法开局）

中长陪伴独白主动避开制造焦虑的强暴击开场，用真实诚恳的姿态瞬间建立心理安全区：
1. **认知边界坦白开局**：直接承认话题复杂、自己仍在摸索，主动交出“标准答案权”（如“我到现在依然说不清它到底是什么，今天也不是来教你该怎么做，只是想聊聊这些年走完一圈才看明白的几件事”）。
2. **自身盲区/笨拙自剖开局**：不立完美人设，先从一个自己曾经搞砸、习惯性逃避或特别拧巴的真实瞬间切入，让听众卸下防备。
3. **隐秘困惑共频开局**：温和说出听众心里憋了很久却很少被平视回应的具体困惑，先让对方感到“被听懂”，再慢慢展开叙述。

### 5 类“必划走”开场黑名单（双模式均禁用）
1. **自我介绍寒暄开场**：`大家好，我是你们的老朋友XX，今天我们来聊聊……`（前 3 秒直接送走 70% 路人）
2. **教科书定义开场**：`所谓昼夜节律，是指生命活动以24小时左右为周期的变动……`（像在上早八专业课）
3. **宏大背景铺垫开场**：`在当今快节奏的社会里，越来越多的人面临着……`（废话文学，没有任何信息增量）
4. **空洞焦虑恐吓开场**：`注意了！再这样做下去你迟早会后悔/身体废掉！`（营销号既视感，极度消耗信任）
5. **无人群指向泛泛发问**：`你们平时喜欢……吗？有没有觉得累？`（群发口吻，受众没有“你在对我说话”的代入感）

## 二、书面语 → 口播人话 20 组高频改造词典

写稿时先用自然话讲一遍，再用下表逐条扫雷。提词器脚本里凡是出现左侧书面语，一律按右侧口语改写：

| 序号 | 书面语雷区 | 问题诊断 | 口播人话改造方案 |
| :--- | :--- | :--- | :--- |
| 1 | `因此` | 报告体连接词，嘴皮生硬 | `所以` / `这样一来` / `结果就是` |
| 2 | `综上所述` / `总而言之` | 像在做年终总结发言 | `说白了` / `一句话说完` / `说到底` |
| 3 | `换言之` | 太书面，听众瞬间出戏 | `翻译成大白话就是` / `说穿了就是` |
| 4 | `众所周知` | 假装大家都知道，爹味极重 | 直接删掉进主题，或改 `你肯定听过这么一句话` |
| 5 | `由此可见` | 议论文腔调 | `你看，这就说明` / `难怪会这样` |
| 6 | `旨在` | 公文高频词 | `就是为了` / `专门用来` |
| 7 | `不仅如此` | 朗诵腔转折 | `更绝的是` / `还没完` / `甚至` |
| 8 | `与此同时` | 新闻联播腔 | `同一时间` / `另一边` / `顺带着` |
| 9 | `前者……后者……` | **听觉灾难**：观众没有眼睛回看上句，必听晕 | 直接重复具体事物名称，绝不用“前者/后者”偷懒 |
| 10 | `就……而言` | 倒装书面壳，拖慢语速 | `拿……来说` / `单看……这一块` |
| 11 | `通过……的方式` | 冗余介词结构，白白拉长气口 | 直接上动词：`靠……` / `用……` / `直接拿……` |
| 12 | `显著提升` | 论文摘要词，毫无画面感 | `直接拉满` / `涨了一大截` / `翻倍往上蹿` |
| 13 | `显著下降` | 抽象无痛感 | `砍掉将近一半` / `断崖式往下掉` |
| 14 | `研究表明` | 权威感生硬，缺乏故事感 | `科学家专门抓了一批人做实验，结果发现` / `实测下来` |
| 15 | `数据显示` | 像在读 PPT | `你看这组数有多吓人` / 直接嘴里报出生活化对比 |
| 16 | `不可或缺` / `至关重要` | 成语堆砌，缺少人味 | `少不了` / `最要命` / `直接决定了……` |
| 17 | 被动长定语（`被……所抑制`） | 英文翻译腔，一口气念不顺 | 改成主动动作：`……一上来，直接把……按在地上摩擦` |
| 18 | 括号补充解释（`（即……）`） | **提词器大忌**：演员会停顿或不知道该不该念 | 拆成自然插入语：`说白了就是……`、`也就是咱们常说的……` |
| 19 | 精确小数（`下降了 42.7%`） | 耳朵抓不住小数点后的细节 | 转化成视觉或分数锚点：`直接砍掉了将近一半` / `十个人里头有四个` |
| 20 | 群指泛称（`大家 / 人们 / 消费者`） | 舞台演讲感，隔着屏幕有墙 | 全部改成单数**“你”**，制造一对一贴耳交谈感 |

## 三、呼吸感、气口与听觉留存滑梯

### 1. 呼吸感与气口铁律

> [!IMPORTANT]
> 本清单聚焦“从书面语到口播人话”的基础打磨；涉及大模型特有的 **`不是X而是Y` 反转口癖、无灵主语、句长突发性（Burstiness）、AI高频大词禁令及六大第一性原理与三维口语自检**，请同步对照 [anti-ai-dehumanization.md](./anti-ai-dehumanization.md) 严格执行。

* **单气口上限 ≤ 25 个口播单位**：两个停顿标点（`，。！？；…—`）之间绝对不能塞进超过 25 个字/英文词。超长句不仅让主播缺氧憋气，也会让观众在 1.25 倍速下瞬间走神。
* **短长短交错节奏**：“短句造势、长句铺垫、单字或短词落锤”。
  * 例：`你以为你在回血？`（7字）`错。`（1字落锤）`你其实是在给大脑强行跨服改时区。`（17字解释）
* **一句话只塞一个核心信息**：禁止用“并且……同时……从而导致……”把三层因果串成一句，直接拆成三句，用停顿隔开。

### 2. 听觉留存机制（短稿滑梯 vs 长稿呼吸）
* **模式 A（`hook` 短/中视频强吸引科普）— 听觉留存滑梯**：每推进 60–90 个字（约 15–20 秒），埋一个**听觉小钩子**把注意力拽回来：
  * 悬念型：`但真正要命的还在后头。` / `最反直觉的一点来了——`
  * 转折打脸型：`等等，先别急着高兴太早。` / `看到这儿你肯定想问……`
  * 利益提醒型：`接下来这一步才是省钱/救命的关键，听好了。`
* **模式 B（`companion` 深度陪伴独白）— 情绪与认知波浪呼吸**：**禁用高分贝催促式留存钩子**（严禁“别划走 / 真正要命的还在后头”），改用自然的情绪与认知波浪推进：**自身笨拙坦白 → 幽微细节白描（蓄能）→ 思考停顿 → 极简命名结晶 → 平缓转入下一层**，靠心理安全区与“被说中心事”留住听众。

### 3. 导演本标记 vs. 纯净提词器规范
* **导演级分镜口播本**：允许且推荐在台词中用方括号标注情绪、重音和动作气口，配合右侧画面/花字建议：
  * `[停顿0.5s]`、`[重音：根本没用]`、`[语速加快]`、`[压低声音像说悄悄话]`、`[无奈摊手笑]`
* **纯净提词器逐字稿**：**绝对禁止任何括号 `()（）[]【】`、斜杠 `/` 或 Markdown 符号 `*#`**。只保留播讲人要开口念出的文字、标点和按呼吸节奏切分的自然换行，确保复制进提词器 App 即可直接开拍。

## 四、科普事实严谨性与平台合规守则

“说人话”与“迎合兴趣”绝不等于“编造伪科学”：
1. **严禁杜撰研究与虚假精确数字**：不确定的科研结论、年份、样本百分比必须先检索查证；若原研究是动物实验或小样本相关性研究，口播中应诚实表述为“动物实验里发现”“目前观察到两者经常绑在一起”，不可把“相关性”吹成“100% 因果”。
2. **科学比喻不可越界**：借用游戏、职场、美妆概念做比喻时，比喻的是**作用机制的关系结构**，紧接着要用一句平实人话兜住科学原貌。
3. **规避平台违禁与绝对化承诺**：涉及健康、医学、护肤、金融话题时，严禁出现“包治”“根除”“绝对安全”“100%有效”“替代药物”等违规词；必要时用自然口语带出免责边界（例如：`“这是日常作息微调，真要是长期严重失眠，还是得老老实实挂个睡眠科让大夫看。”`）。
