# 身份定义与目标人群兴趣转译指南

本指南用于在撰写任何科普口播剧本前，先把**“我是谁（说话人身份）”**、**“我在跟谁说（目标人群与兴趣圈层）”**以及**“如何把硬核知识翻译成对方兴趣母语”**三件事彻底锚定，杜绝“专家自说自话”或“受众画像流于泛泛年龄段”。

---

## 一、身份定义三维画布（Speaker Persona Canvas）

口播不是论文朗读，观众在 3 秒内决定的是“愿不愿意听**这个人**说话”。身份定义必须拆解为以下三个可落地维度：

### 1. 信任锚点（双路径：专业战绩 vs 坦诚经历）
* **反面做法（干瘪头衔）**：`我是XX大学营养学硕士`、`我是十年临床经验医师`、`我是高级工程师`。观众无感，且天然拉开权威距离。
* **正面做法一（`hook` 科普路径 — 带战绩/带疤痕的实战身份）**：用**“你的背景 + 帮什么样的人解决过什么具体麻烦”**来代替纯职称。
  * 营养学硕士 → `帮 300 多个管不住嘴的打工人戒掉下午茶崩溃的营养师`
  * 皮肤科医生 → `每天在门诊看几百张“刷酸烂脸”案例的皮肤科医生`
  * 机械/物理背景 → `专门用拆家电的思路帮你看穿智商税的工科老哥`
* **正面做法二（`companion` 深度独白/陪伴路径 — 坦诚局部的同行者）**：不必堆砌权威头衔，直接锚定**“亲历过同类挣扎、敢先承认自身盲区与弯路的真实同行者”**，靠认知谦卑与坦诚自剖建立深层信任。

### 2. 关系站位五象限（Relational Stance）
选定主讲人与目标人群之间的**心理站位**，整篇剧本必须严格守住该站位，不得中途出戏（OOC）：

| 关系站位 | 心理距离与语气温度 | 标志性句式模板 | 绝对禁止（OOC雷区） |
| :--- | :--- | :--- | :--- |
| **① 损友嘴替型**<br>(Sharp Bestie) | **极近 / 毒舌但护短**<br>像坐在对面喝奶茶吐槽的聪明朋友 | “说实话，这坑我当年也踩过，简直离大谱……”<br>“你是不是又信了那套鬼话？” | 突然开始端着架子说“综上所述，我们要保持良好作息” |
| **② 温暖前辈 / 知心学姐型**<br>(Warm Mentor) | **贴近 / 笃定、共情、不制造焦虑**<br>像过来人轻拍你肩膀递一杯热茶 | “我懂那种熬到凌晨两点、手还是忍不住点开外卖软件的无力感。”<br>“其实你只需要把顺序稍微换一下……” | 居高临下指责受众“懒惰”“无知”，或使用刻薄嘲讽 |
| **③ 硬核极客拆解员型**<br>(Geek Mechanic) | **平视 / 亢奋、讲究逻辑与拆解快感**<br>像带你潜入后台看系统源码的技术控 | “你把人体想象成一台跑满负载的服务器……”<br>“拆开看其实特别粗暴，一共就三步。” | 只给情绪不给机制，或者堆砌未经解释的生僻术语 |
| **④ 行业一线内幕员型**<br>(Insider Observer) | **半步领先 / 冷静、直白、捅破窗户纸**<br>像业内熟人拉你到角落说真话 | “干这行十年，最怕你一上来就交这笔钱。”<br>“厂家宣传页上绝不会写的那半句话是……” | 空喊“黑幕”却拿不出客观原理或对照事实支撑 |
| **⑤ 坦诚同行者 / 深夜老友型**<br>(Candid Companion) | **平视、克制、低攻击性 / 不催促、不站队**<br>像深夜暖光下愿意先剖析自己弱点的老朋友 | “我到现在也说不清标准答案，但这几年走了弯路才慢慢懂了一点……”<br>“其实我当年也习惯逃避，总以为不说就过去了……” | 端起全知导师架子下判断、使用“注意了！下面最关键！”式短视频焦虑留存话术，或居高临下评判他人 |

### 3. 语言指纹卡（Voice Fingerprint）
在写第一句台词前，填好下面 6 项，确保口播逐字稿“闭上眼也能听出是谁在说话”：
1. **自称**：`我` / `老王` / `学姐` / `阿K`（避开官腔“本博主”“笔者”）
2. **对观众称呼**：统一用单数**“你”**，可在前 3 秒嵌入圈层昵称（如“熬夜打排位的你”“早八赶地铁的姐妹”，禁止“各位观众朋友们”“大家”）
3. **口头禅 / 标志转折词**：1–2 个即可（如“讲到这儿我想到个事”“你先别急”“说白了其实挺有意思”——严禁套用“听我一句劝/说句扎心的”等流水线网红话术）
4. **句式脾气**：短促炸裂型（平均 8–12 字断句） vs 娓娓道来型（12–18 字层层推进）
5. **身份禁用词表**：列出绝对不符合该身份的词汇（如损友型禁用“由此可见”“务必谨遵”）
6. **本期专属物理锚物与定制开合（反跨稿同质化）**：强制为每期剧本从当期核心现场锁定 1 个强绑定的物理道具或具体瞬间（如凌晨三点手机电量红条、写满批注的实验本页角、发烫的器材外壳），开篇起兴与结尾收束必须紧扣该锚物，**严禁跨期复用固定模板寒暄、万能生活动作壳或通用求评论结尾句式**。

## 二、目标人群与兴趣圈层深挖图谱（Target Audience & Hobby Profiling）

拒绝使用“18–35 岁年轻群体”这类空洞标签。必须锁定**“高频生活摩擦场景 + 兴趣爱好母语 + 内容爽点 + 劝退雷区”**。

### 四维深挖自检
1. **高频生活摩擦场景**：具体到**时间 + 地点 + 微痛点**（例：`周日凌晨两点刚推完高难副本、周一早上八点半对着工位电脑脑袋嗡嗡作响`）。
2. **兴趣爱好与内容消费习惯**：平时刷什么、玩什么、追什么梗（决定你用什么语言去“借壳科普”）。
3. **核心情绪回报（爽点）**：是想看**爽感打脸**、**省钱避坑**、**掌控感提升**，还是**自我和解（脱罪感）**？
4. **劝退雷区（绝对别踩）**：受众最讨厌被怎么说教？

## 三、核心内容转译双路径（兴趣同构 vs 幽微经验命名）

根据所选口播模式，在以下两条转译路径中二选一，严禁混用错位：

* **路径 A（`hook` 科普模式）**：走下方“科学概念兴趣转译器四步法”，把硬核机制翻成目标受众兴趣圈层里的同构规则。
* **路径 B（`companion` 深度独白 / 人文心理模式）**：**不强套游戏、消费等圈层黑话**，改用**“幽微经验白描 → 蓄能命名结晶”三步法**：
  1. **剥离学术大词与标签**：先放下专业术语与心理学名词（不掉书袋）；
  2. **逐帧白描隐秘心理动作（铺足蓄能池）**：把当事人在关键瞬间的真实退缩、犹豫、自我防御、委屈算账过程用平实大白话慢慢拆开；
  3. **蓄能后一句命名结晶**：等情绪与认知在细节里攒满后，自然落出一句极简日常短句，替听众精准命名这种一直憋在心里说不出的状态（绝不无铺垫空降金句）。

### 路径 A 详解：科学概念“兴趣转译器”四步法（Interest-Bridge Science Translator）

把硬核知识点精准打进受众兴趣圈层，严格走完以下四步：

1. **Step A — 剥离专业名词，提炼“底层关系模型”**
   不要盯着术语本身，而是问：**这个科学机制本质上是什么关系？**
   * 常见底层模型：`受体抢坑位`、`蓄水池溢出`、`错误信号劫持`、`正反馈死循环`、`透支利息滚雪球`、`阈值触发`。
2. **Step B — 在目标兴趣世界里找“同构系统”**
   在受众最熟悉的兴趣体系中，找到结构一模一样的机制。
   * 例如：“咖啡因阻断腺苷受体”的本质是`占位抢坑` → 对游戏党就是`假占格子不让疲劳Debuff上身，但后台读条还在悄悄涨`。
3. **Step C — 用“可视化动作动词”替代抽象名词**
   口播听众看不见字幕结构，必须把名词改成正在发生的画面动作：
   * `皮质醇激活奖赏回路` → `大脑直接拉响逃命警报，抢过方向盘逼你狂炫甜食`。
4. **Step D — 科学边界护栏（严防伪科学变形）**
   打比方只能借用“关系结构”，绝不能把比喻当成科学事实本身。写完转译后必须自检一句：**“这个比喻精确覆盖了核心机制吗？它在哪里停住才不会误导观众？”** 必要时用半句大白话点出边界（例如“它不是真的把你的胃撑大，而是把饱腹感信号屏蔽了”）。

## 四、可选初始配置：主干线路 × 逐节点分叉拓扑通用模型

当选题涉及**多阶段演化过程、成长路径、历史演进、产业链条或长因果链路**时，支持用户在 Step 1 提供预设“主干节点序列”，再围绕每一个主干节点展开多线分叉对照。

### 1. 初始配置语法与启发规则
* **用户指定线路**：支持以短横线或箭头给出抽象或具体序列（例如 `Stage_1 → Stage_2 → Stage_3 → Stage_4`）。
* **用户未指定线路**：若话题天然存在多个递进阶段，Step 1 主动提议 **2–3 条典型演进拓扑结构**供用户拍板，确认后逐节点挂载平行对比。

### 2. 线路现实可行性核查算子（3 Reality-Check Operators）
拿到输入链路后，**严禁不加核查按字面硬拼成单一主体亲历**。必须先运行以下三个通用校核算子：
1. **算子 ① 时间序校核（Chronological Order）**：检查节点之间是否存在先后倒置、共时发生或倒叙错位；若前置节点实际发生在后段，应明确重构为**倒叙切口 / 结果倒推**，避免时间线穿帮。
2. **算子 ② 制度/科学/因果门槛校核（Eligibility & Causality Check）**：核验 `Stage_k → Stage_{k+1}` 是否具备现实制度通道、物理规律或客观准入条件；若存在现实断点，**严禁强行把走不通的链路硬安在同一个主角身上**。
3. **算子 ③ 断点修正双解（Dual Resolution Strategy）**：当触发断点时，采用以下两套方案之一重构拓扑（并向用户说明调整原因）：
   * **方案 A（写实单主干 + 平行侧枝全覆盖）**：修正主干节点使单一主角完全自洽，同时把被剔除的分支交由对照侧枝人物亲历，确保用户指定的每个概念节点都在同一体系下得到正面科普。
   * **方案 B（多人物群像接力）**：明确用 2–3 位身处不同约束条件下的平行主体分工承接各段路线，严禁逻辑硬套。

### 3. 节点规模 ↔ 时长 / 分集预算对照表

| 链路节点规模 | 建议时长与体量 | 制作与信息压缩策略 |
| :--- | :--- | :--- |
| **1–2 节点（单点纵深）** | 60–180 秒（250–750 字） | 1 条主线事件 + 1–2 个高反差对照侧枝 |
| **3–4 节点 + 逐节点分叉** | 4–6 分钟（1000–1500 字） | 主干叙事串联 + 每节点 1 组机制对比 |
| **5–7 节点 + 逐节点分叉** | **6–10 分钟深度长篇（1500–2500 字）**，或拆为 **上 / 下两集**（每集 4–5 分钟） | **严禁把 ≥5 个节点硬塞进 3 分钟内**，防止节奏崩坏成干瘪提纲流水账 |

### 4. 单节点四元展开公式（Node Expansion Formula）

每个主干节点必须按以下固定四元组展开，杜绝孤立报幕与纸片人配角：

> **节点完整结构 = `① 主干具身体验` × `② 对照侧枝人物（反 NPC 三件套）` × `③ 双面真实账（可见收益 + 隐性代价）` × `④ 自然回干转场`**

* **① 主干具身体验**：主讲人在此节点的具体动作、现场质感与犹豫细节（用感官与成本代替抽象评价）。
* **② 对照侧枝人物（反 NPC）**：必须给出在同节点选择另一条路线的平行角色，并补足其**生活特征/原话口吻 + 个人动机**，不可只当作宣读数据的播音机。
* **③ 双面真实账**：在同一节点正面拆解两条路线的底层机制差异，**必须成对写出双方各自的可验证甜头与真实摩擦代价**（严禁单向吹捧或单向卖惨）。
* **④ 自然回干转场**：依托人物关系、资源流向或现场道具顺势滑入下一个 `Stage_{k+1}`，同时核对**人物账本**——开篇及前段点名的每个人物必须在对应阶段落地闭环，0 失踪。
